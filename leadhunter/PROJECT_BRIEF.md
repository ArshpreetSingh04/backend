# LeadHunter — Project Brief

## Purpose
LeadHunter is a lead-generation and qualification backend. It discovers,
enriches, and scores prospective leads so that downstream sales workflows
can prioritize outreach.

## Scope (M0)
- Establish project control files and milestone tracking.
- Define the high-level direction and success criteria.
